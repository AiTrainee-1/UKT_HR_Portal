The wording of every message is copied from the application's message catalogue, so it matches what the server sends. Lines that have nothing to say (for example a missing note) are left out, exactly as the server does.

Sent as: a text; a PDF or an image with the wording as its caption; a contact card. No message carries a link to the Employee Web App. The ID card picture is a drawn sample. Dates, amounts and names are samples too. A message is sent in the live system only when its switch on the WhatsApp Control page is on.

This page needs no server: open the file straight from disk. The PNG export is made in your browser (current Chrome or Edge recommended) and nothing is uploaded.
